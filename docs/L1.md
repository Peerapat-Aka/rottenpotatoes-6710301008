## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | รวบรวมไลบรารีพื้นฐานสำหรับการทำ Unit Testing และ Integration Testing ใน Spring Boot โดยมี BOM กำหนดเวอร์ชันที่ทำงานร่วมกันได้อย่างสมบูรณ์ |
| junit-jupiter | เครื่องมือหลักสำหรับการเขียนและประมวลผล Test Cases (JUnit 6) ผ่าน annotation เช่น `@Test` |
| assertj-core | เครื่องมือสำหรับการเขียน Assertion ในรูปแบบ Fluent API เช่น `assertThat(...).isEqualTo(...)` ทำให้อ่านเงื่อนไขและข้อความแจ้งเตือนเมื่อ Test ล้มเหลวได้ชัดเจน |
| mockito-core | เครื่องมือสร้าง Mock object (Test Double) เพื่อจำลองพฤติกรรมของ Class หรือ Service อื่นที่ยังไม่ได้ทดสอบ |
| json-path | ใช้สำหรับค้นหาและตรวจสอบค่าในโครงสร้างข้อมูล JSON สำหรับการทดสอบผลลัพธ์ของ API |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
- Red bar แรกพิสูจน์ว่า Test Case ที่เขียนขึ้นนั้นสามารถตรวจจับข้อผิดพลาดได้จริง และยืนยันว่าฟีเจอร์ที่ต้องการยังไม่เคยมีอยู่ก่อนที่จะลงมือเขียนโค้ด หากไม่มี Red bar มาก่อน เราอาจเขียน Test ที่ผ่านตลอดเวลา (Always-pass/Tautology) โดยไม่ได้ทดสอบฟังก์ชันจริง การมี Red แล้วตามด้วย Green จึงเป็นการยืนยันว่าโค้ดใหม่ที่เราเขียนเข้าไปคือสิ่งที่ทำให้ระบบทำงานถูกต้องจริง
